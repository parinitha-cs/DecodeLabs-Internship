# DecodeLabs Backend Development Internship

This repository contains the projects completed as part of my Backend Development Internship at DecodeLabs.

## Projects

### Project 1 – REST API Development

A Flask-based REST API demonstrating basic backend and REST API concepts.

**Technologies:** Python, Flask, REST API, JSON, Postman

📁 Folder: `Project-1`

---

### Project 2 – Database Integration (CRUD)

A Flask REST API integrated with SQLite for persistent user data storage.

**Features:**
- Create users
- Read users
- Update users
- Delete users
- Duplicate email prevention
- SQLite database integration
- SQLAlchemy ORM
- Postman API testing

**Technologies:** Python, Flask, Flask-SQLAlchemy, SQLAlchemy, SQLite

📁 Folder: `Project-2`
